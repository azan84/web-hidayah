# Site chat assistant

The "Ask about my research" button on the main pages (`ask-hidayah.js` + `ask-hidayah.css` at the site root)
talks to this Cloudflare Worker, which holds the Anthropic API key and answers with Claude
(`claude-haiku-5-5`, low effort) using only the text published on the site.

Live endpoint: `https://hidayah-site-chat.azan-sapardi.workers.dev/chat`

## After changing the website

The bot's knowledge is a snapshot of the HTML pages (`src/knowledge.js`, generated by
`scripts/build-knowledge.mjs` — it includes `index`, `academics` (incl. the publication list), `students`,
`personal`, `blog` (incl. the post list from `blog-posts.js`), every `blog-*.html` and the JSON-LD profile
data). Quiz pages are left out, and the bot won't give quiz answers. Links written as `href="#"` are marked
"(link not available yet)" so the bot doesn't send people to them. Redeploy so it learns new content:

```bash
cd chat-worker
npm install        # first time only
npm run deploy     # rebuilds knowledge.js, then wrangler deploy
```

New pages outside that list need adding to `CORE` in `scripts/build-knowledge.mjs`, and a
`<script src="ask-hidayah.js?v=1" defer></script>` tag if the chat button should appear there.

## Local testing

```bash
# chat-worker/.dev.vars (gitignored):
#   ANTHROPIC_API_KEY=sk-ant-...
#   ALLOW_LOCALHOST="true"
npm run dev                                   # worker on http://localhost:8787
python3 -m http.server 8000 --directory ..    # site on http://localhost:8000
```

The widget automatically uses the local worker when the page is served from `localhost` / `127.0.0.1`.

## Key, limits and cost

- API key: `npx wrangler secret put ANTHROPIC_API_KEY` (stored encrypted in Cloudflare, never in the repo).
- Only `https://hidayah.biomechemical.com` may call the endpoint (`ALLOWED_ORIGINS` in `wrangler.toml`);
  browsers enforce that, but scripts can fake the Origin header, so volume is also capped: 8 questions/minute
  per visitor IP and 40/minute site-wide. Questions are capped at 1,500 characters, history at 12 messages,
  replies at 2,000 tokens.
- The ~6k-token site snapshot is prompt-cached: about $0.0005 per answer while warm, ~$0.004 for the first
  question after 5 idle minutes. Set a monthly spend limit in the Anthropic Console as a backstop.
- The bot tells visitors to email rather than use the Personal page's form, because that form doesn't
  send messages yet (`handleContactSubmit` in `script.js` only shows "Message Sent!").
- `npx wrangler tail` shows live requests, including a `usage` line per answer.
